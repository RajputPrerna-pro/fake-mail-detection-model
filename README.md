# Fake Mail Detection Model 📧🤖

This project is a **Machine Learning based Fake Mail Detection Model** that predicts whether an email is **Fake/Spam** or **Genuine/Real**.

## 📌 Project Overview

The model analyzes email-related features and uses Machine Learning techniques to classify emails into different categories.

## 🛠️ Technologies Used

* Python
* Pandas
* NumPy
* Scikit-learn
* Matplotlib
* Machine Learning

## 🔍 Workflow

1. Load the dataset
2. Clean and preprocess the data
3. Perform data analysis
4. Split data into training and testing sets
5. Train the Machine Learning model
6. Evaluate model performance
7. Predict whether an email is fake or genuine

## 📂 Project Files

* `fake_mail_detection_model.py` — Main Machine Learning model
* `dataset.csv` — Dataset used for training
* `README.md` — Project documentation

## 🎯 Objective

The main objective of this project is to build a Machine Learning model that can help identify suspicious or fake emails and improve email security.
